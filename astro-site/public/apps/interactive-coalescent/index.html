Coalescent With Changing Population Size

Explore how time-varying population size changes the geometry of coalescent histories. This interactive view complements the mathematical tutorials with a manipulable demographic picture.

How To Use It

Switch between parametric and piecewise populations, personalize the trajectory, and inspect how changing demographic assumptions reshape waiting times and branching structure.

Paste Population Vector

Enter population sizes separated by commas, spaces, or newlines. The vector should match the number of grid points.
