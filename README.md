# Filippo Monti Academic Website

Personal academic website for Filippo Monti, deployed at:

https://fil-monti.github.io

The active website is the Astro project in `astro-site/`. The repository also contains older or legacy site artifacts, but day-to-day edits should happen inside `astro-site`.

## Quick Start

From the repository root:

```bash
cd astro-site
npm install
npm run dev
```

The dev server runs on `127.0.0.1` and prints the local preview URL.

Before committing changes:

```bash
cd astro-site
npm run check
npm run build
```

## Components

The most important reusable components are:

- `BaseLayout.astro`
  - wraps every page
  - imports `global.css`
  - imports KaTeX CSS
  - sets metadata
  - controls dark/light theme initialization
  - includes the header, footer, and search overlay

- `SiteHeader.astro`
  - top navigation
  - search `?` button
  - theme switch
  - mobile menu

- `ProjectCard.astro`
  - paper/manuscript cards
  - highlights `Monti, F.` in author lists
  - renders inline math in abstracts using `$...$`

- `CitationPreview.astro`
  - hover preview for citations in homepage notable contributions
  - finds the matching paper by exact title in `researchProjects`

- `ContentCard.astro`
  - general card component used by teaching and other card-like content

- `PageHero.astro`
  - reusable page title and eyebrow section

- `PageSideNav.astro`
  - vertical page-local navigation, currently used on Research

- `GravityMap.astro`
  - interactive model gravity map component, currently available but not shown on the Research page

## Content Data

### Navigation

Edit `navItems` in `astro-site/src/data/site.ts`.

Example:

```ts
export const navItems = [
  { label: "Home", href: "/" },
  { label: "Research", href: "/myresearch/" },
  { label: "Papers", href: "/publications/" },
  { label: "Teaching", href: "/myteaching/" },
  { label: "Software", href: "/software/" },
  { label: "CV", href: "/cv/" }
];
```

The search index also reads `navItems`, so new navigation entries become searchable automatically.

### Profile

Edit `profile` in `astro-site/src/data/site.ts`.

Important fields:

- `name`
- `email`
- `github`
- `cv`
- `portrait`
- `heroImage`
- `teachingImage`

Paths beginning with `/assets/...` refer to files in `astro-site/public/assets/...`.

### Papers

Edit `researchProjects` in `astro-site/src/data/site.ts`.

Each paper has this shape:

```ts
{
  title: "Paper title",
  authors: "Monti, F., and Suchard, M. A.",
  year: "2026",
  status: "In press",
  journal: "Proceedings of the National Academy of Sciences",
  links: [
    { label: "arXiv", href: "https://arxiv.org/abs/..." },
    { label: "Code", href: "https://github.com/..." }
  ],
  topics: ["CTMCs", "Adjoint methods"],
  abstract: [
    "First abstract paragraph.",
    "Second abstract paragraph with $O(K^3 + NK^2)$ inline math."
  ]
}
```

Notes:

- `ProjectCard.astro` automatically bolds `Monti, F.` in author strings.
- The Papers page generates filters from `topics` and `status`.
- First-author filtering uses `authors.trim().startsWith("Monti, F.")`.
- Inline math in abstracts uses single-dollar syntax, for example `$O(K^3 + NK^2)$`.
- Paper anchors are generated by slugifying the title, for example `/publications/#paper-nonparametric-modeling-of-continuous-time-markov-chains-with-scalable-exact-and-approximate-gradients`.

### Homepage Citation Previews

Homepage notable contributions use `CitationPreview`.

Example:

```astro
<CitationPreview
  label="Monti et al., 2026a"
  title="Nonparametric Modeling of Continuous-Time Markov Chains with Scalable Exact and Approximate Gradients"
/>
```

The `title` must exactly match a `researchProjects` title. If it does not match, the link falls back to `/publications/` and no paper preview is shown.

### Research Focus

Edit these arrays in `astro-site/src/data/site.ts`:

- `researchFocus`
- `applicationAreas`

These feed the Methodology and Areas of Application boxes on the Research page.

### Teaching

Edit `teachingGroups` in `astro-site/src/data/site.ts`.

The homepage currently shows:

- the first entry from the Teaching Assistant group
- the first entry from the non-Teaching Assistant group

The full Teaching page shows the complete teaching history.

### Software

Edit `softwareEntries` in `astro-site/src/data/site.ts`.

Software logos live in `astro-site/public/assets/img/logos/`.

## Images, CV, and Static Assets

Astro serves files from `astro-site/public/` at the site root.

Examples:

- `astro-site/public/assets/img/myself.jpg` is available as `/assets/img/myself.jpg`
- `astro-site/public/assets/cv/FilippoMonti_CV.pdf` is available as `/assets/cv/FilippoMonti_CV.pdf`
- `astro-site/public/assets/img/logos/beast-icon.png` is available as `/assets/img/logos/beast-icon.png`

When adding a new image:

1. Put it somewhere under `astro-site/public/assets/img/`.
2. Reference it with a root-relative path beginning with `/assets/img/...`.
3. Prefer compressed images with reasonable dimensions.

## Styling Guide

Global styles live in `astro-site/src/styles/global.css`.

Key variables are defined at the top:

```css
:root {
  --blue: #025196;
  --gold: #fdb338;
  --ink: #121923;
  --body: #27313f;
  --muted: #657285;
  --surface: #ffffff;
```

## Homepage Hero Title Rotation

The homepage title rotates between two titles in `astro-site/src/pages/index.astro`.

Look for:

```ts
const heroTitles = [
  {
    lines: [
      { text: "Modeling evolution", tone: "ink" },
      { text: "across space and time.", tone: "blue" }
    ]
  },
  {
    lines: [
      { text: "Scalable inference for", tone: "ink" },
      { text: "continuous-time Markov", tone: "blue" },
      { text: "processes.", tone: "blue" }
    ]
  }
];
```

The interval is currently `10000` milliseconds.

The fixed three-line title area is styled by `.hero-title`, `.hero-title-slide`, and `.hero-title-line` in `global.css` so the rest of the homepage does not move when the text changes. Titles with fewer than three lines are vertically centered in the window.

## Deployment

Deployment is handled by GitHub Actions:

```text
.github/workflows/deploy-astro.yml
```

On every push to `main`, GitHub Actions:

1. checks out the repository
2. installs Node 22
3. runs `npm ci` inside `astro-site`
4. runs `npm run check`
5. runs `npm run build`
6. deploys `astro-site/dist` to GitHub Pages

Do not commit `astro-site/dist`; it is generated during deployment.

## Common Tasks

### Add a Paper

1. Edit `astro-site/src/data/site.ts`.
2. Add a new object to `researchProjects`.
3. Fill `title`, `authors`, `year`, `status`, `links`, `topics`, and `abstract`.
4. Run:

```bash
cd astro-site
npm run check
npm run build
```

### Add a Homepage Citation Preview

1. Add or identify a paper in `researchProjects`.
2. In `astro-site/src/pages/index.astro`, import/use:

```astro
<CitationPreview label="Monti et al., 2026" title="Exact title from researchProjects" />
```

3. Make sure the `title` is an exact string match.

### Change Header Navigation

1. Edit `navItems` in `astro-site/src/data/site.ts`.
2. If styling or spacing needs adjustment, edit `.desktop-nav` and `.header-actions` in `global.css`.

### Change the CV

Replace:

```text
astro-site/public/assets/cv/FilippoMonti_CV.pdf
```

The website already points to `/assets/cv/FilippoMonti_CV.pdf`.

### Change Education Timeline Text

Edit the education list directly in:

```text
astro-site/src/pages/index.astro
```

Look for `<ol class="education-timeline">`.

### Change Education Logos

Education logos are referenced in `astro-site/src/pages/index.astro` and stored in:

```text
astro-site/public/assets/img/logos/education/
```

### Change the Teaching Homepage Cards

The card data comes from `teachingGroups` in `astro-site/src/data/site.ts`.

The homepage displays the first entry in each relevant group. To change the homepage TA card, change the first Teaching Assistant entry.

### Change Colors

Edit the CSS variables at the top of `astro-site/src/styles/global.css`.

Also check the dark-theme variables in `html[data-theme="dark"]`.
